# Visual Novel

## 📸 Overview 📸
- A (very) short concept for a Visual Novel that implements POO elements and uses the SFML library.

## ✨ Mechanics ✨
- **Dialogue Scenes** : to progress you must click anywhere on the screen.
- **Choice Scenes** : when multiple choices appear on the screen, you must choose one of the options and the dialog will change with it. 
- **Investigation Scene** : clicking around the scene will prompt descriptions of the said object.
**Attention!** During the investigation scene, you have to click on the sides of the screen to move between shots. To progress, to the next part of the game you must click the desk!

## 🛠️ Technical skills 🛠️
- **Language** : C++ 17
- **IDE** : CLion
- **OOP Concepts** : STL, encapsulation, throwing and catching exceptions, inheritance, templates, Design Patterns (Singleton)
- **SFML Library** : loading auditive and visual assets, window usage, clicking event
